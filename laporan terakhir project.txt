BUG REPORT - SURAT REKOMENDASI (FATAL LAYOUT BUG)
==================================================

[Jenis Surat]
Surat Rekomendasi (Kode 421.7/015.SMABHY.S/402.4.9.24/2026)

[Detail Bug]
1. Out of Bounds / Layout Truncation (Elemen Melayang Keluar Kertas):
   - Teks tanggal ("Surabaya, 26 Agustus 2026") dan "Kepala Sekolah," terlempar keluar dari margin kertas/container (terpotong di bagian bawah).
   - Penyebab: Margin/padding container utama terlalu tinggi atau CSS height tidak terkunci (overflow: visible), sehingga elemen footer terdorong melampaui batas Halaman 1.

2. Duplicate Footer Element (Elemen Ganda):
   - Teks tanggal & jabatan muncul 2 kali (satu menimpa stempel, satu lagi melayang di luar kertas bawah).
   - Penyebab: Kemungkinan ada duplikasi tag HTML di template atau bentrokan styling antara print CSS dan display biasa.

3. UI Layout Misalignment (Stempel & TTD):
   - Stempel dan TTD masih offset menimpa teks nama penandatangan secara acak.

[Solusi Cepat CSS]
Bungkus seluruh surat dalam satu wrapper:
.halaman-surat {
  width: 210mm;
  height: 297mm; /* Ukuran A4 */
  padding: 20mm;
  box-sizing: border-box;
  position: relative;
  overflow: hidden; /* Biar gak ada elemen keluar kertas */
}

Atur footer TTD pakai posisi absolut dari bawah container:
.footer-ttd {
  position: absolute;
  bottom: 25mm;
  right: 20mm;
}

FEATURE REQUEST - MULTI-PENERIMA SURAT TUGAS (DYNAMIC FIELD / KOLEKTIF)
==================================================

[Halaman Form]
INPUT SURAT TUGAS

[Problem Statement]
Form Surat Tugas saat ini hanya mendukung 1 penerima tugas (Single Input). 
Jika tugas diberikan ke 2 orang atau lebih (kelompok/kolektif), form tidak bisa menampung data tersebut.

[Usulan Solusi UI/UX]

1. Dynamic Repeater Form (Cocok untuk 2-5 Orang):

   - Saat diklik, JS akan memunculkan row input baru (Nama, Kelas/Unit, NIS/NIP).

   - Sediakan Toggle/Switch: "Input Perorangan" VS "Input Kolektif (Banyak)".
   - Jika Mode Kolektif aktif, field single berubah jadi Textarea (atau Auto-helper Master Data).
   - Efek di Hasil Cetak: Jika penerima banyak, layout otomatis dirender menjadi TABEL DAFTAR PENERIMA TUGAS di dalam surat.

[Implementasi Template Cetak (Backend/Frontend View)]
- Tambahkan logika kondisional pada template cetak:
  * Jika count(penerima) == 1 -> Tampilan Format Single.
  * Jika count(penerima) > 1 -> Tampilan Format Tabel / Multiple List.

BUG REPORT - JS AUTOFILL HELPER STRICT VALIDATION BUG
==================================================

[Halaman Form]
INPUT SURAT UNDANGAN (dan Form dengan Penerima Custom/Eksternal)

[Detail Bug]
1. Rigid Validation / Hardcoded Autofill Scope:
   - Function JS Auto-helper mewajibkan teks yang diketik di field "Yth. / Penerima Undangan" harus cocok dengan database (Siswa/Guru).
   - Jika diisi teks bebas/eksternal (contoh: "Bapak/Ibu Orang Tua / Wali Murid Kelas X"), script melempar error "Data tidak ditemukan..." dan menolak/memblokir input.
   - Penyebab: Validasi event listener (`oninput` / `onchange` / `blur`) tidak memiliki fallback option untuk "Custom / Free-text Input".

[Solusi Fix Code (JavaScript)]
Tambahkan pengkondisian agar user tetap bisa memilih opsi "Gunakan teks kustom" atau matikan auto-search jika input tidak menemukan match di DB:

// Contoh Logic JS Fix:
function handleAutofill(inputVal) {
    let result = searchDatabase(inputVal);
    
    if (result.length === 0) {
        // Jangan dikunci/error! Biarkan jadi teks bebas (Free-text mode)
        hideErrorMessage();
        allowCustomInput(inputVal); 
    } else {
        showDropdownSuggestions(result);
    }
}
